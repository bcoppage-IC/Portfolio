# Portfolio

Personal portfolio site for Ben Coppage. Built with plain HTML, CSS, and a small amount of vanilla JavaScript. No frameworks or build step.

## Files

- `index.html`: page content and the inline script
- `style.css`: all styles
- `photo.jpg`: headshot (add your own, square crop)
- `resume.pdf`: resume for the download button (add your own)

## View it locally

Open `index.html` in a browser. No install is needed.

## Features

- Sticky nav with active section underline
- Consultative / Data toggle that changes the tagline and skill emphasis
- Count-up stats and fade-in sections, off when reduced motion is set
- Responsive down to 360px
- Semantic HTML, visible focus states, and WCAG AA text contrast

## Deploy

1. Push the files to the repo's main branch.
2. In the repo, go to Settings, then Pages.
3. Set the source to the main branch, root folder, and save.
